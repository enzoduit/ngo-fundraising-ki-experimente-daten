# KI im NGO-Fundraising: 20 Experimente in Zahlen

Zitierbarer Datensatz mit den Kennzahlen aus den dokumentierten FlyRaising-Experimenten (learn.flyraising.com): ROAS 0,15 → ~3,53 in vier Jahren (EXP 01), +84 % Conversion (EXP 02), +47 % Response / +34 % Einnahmen pro Brief (EXP 03), ein Fehlschlag (EXP 08) u. a. Dazu ein Snapshot des NGO AI Visibility Benchmarks (94 NGOs, Ø Share of AI Voice 12,4 %).

**Aktuelle Version:** https://info.flyraising.com/ki-fundraising-experimente-daten/

## Dateien
- `data/ki-fundraising-experimente.json`: vollständiger Datensatz
- `data/experimente.csv`: Experimente mit Status und Kennzahl
